Fixes in the frameworks agents run on

Three merged pull requests and one open pull request. I did not start these projects. These are the fixes I shipped.

Pipecat #5760: keep function call timeouts armed

Pipecat is a framework for realtime voice agents. Tool call timeouts were being cancelled by intermediate results. The fix keeps the function call timeout armed across intermediate results, and I added tests.

github.com/pipecat-ai/pipecat/pull/5760
Merged

Genkit #6346: accept base64 embeddings from OpenAI

Genkit is a framework for building AI applications. With the OpenAI plugin, requesting the base64 encoding format caused embedding validation to fail. The fix decodes base64 embeddings so retrieval works.

github.com/genkit-ai/genkit/pull/6346
Merged

Strands Agents harness SDK #4313: JSON safe AgentResult

Strands Agents is an agent SDK. When Bedrock returned raw bytes, AgentResult.to_dict could not be turned into JSON. It now serializes cleanly.

github.com/strands-agents/harness-sdk/pull/4313

Open, under review

Open

LiveKit Agents #7186: bound the EndCallTool wait

LiveKit Agents is a framework for realtime voice agents. This pull request bounds the wait for tool reply audio in EndCallTool, so a voice session does not hang on teardown when that reply times out. It is still open and has not been merged.

github.com/livekit/agents/pull/7186
