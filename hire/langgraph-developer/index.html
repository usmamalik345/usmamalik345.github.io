What I build

LangGraph agents that do real work

Tool using agents

Agents that call your APIs, databases and internal tools, with clear state between steps, so you can see why the agent did what it did.

Guards around the graph

Token and budget caps per request, prompt injection checks and an append only audit log. This is the same idea as BleedStop, my LLM cost and security guard.

Retrieval inside the agent

RAG steps with embeddings and vector search, and answers that cite their source. See the RAG developer page.

Deployment

Docker, Kubernetes with Helm, GitHub Actions CI/CD and AWS, so the agent ships like any other service.
