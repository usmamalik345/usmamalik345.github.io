Delivery

Process-driven delivery, with the writing first

I work in Pakistan Time, PKT (UTC+5). A 9:00 start in Berlin, Munich, Vienna or Zurich is 13:00 PKT in winter (CET) and 12:00 PKT in summer (CEST), so a German morning is the middle of my day. The Europe page has the full EU-wide hour picture. What is different here is how I would run the work.

Teams in this region often want a paper trail: a written brief, a design that can be reviewed before the build, pull requests that explain the change, and a test report that says what passed and what did not. That is already how I publish my own work. The BleedStop case study and the Agent Receptionist case study are written so you can check the numbers without a call. On a contract I would keep the same habit: tickets with context, evals from day one, and a short written update instead of a vague status meeting.

I will not pretend that a process replaces a conversation. We can still use the shared CET morning for decisions that need a screen. I would rather use that hour to review a failing eval or a design choice than to recap an email. I work in English. I do not claim German as a working language.

Data

Data residency as an engineering option

Where the data lives is a deployment choice I can make with you. It is not a certification, and it is not the same problem in Switzerland as it is in Germany or Austria.

I deploy applications on AWS, with Docker, Kubernetes and GitHub Actions. If you already run in an EU region, I can build and operate the agent there, so personal data does not have to leave that region for me to do the job. If you need a development set, I would rather use redacted, synthetic or otherwise agreed data than keep a production copy on my laptop. I can sign an NDA and follow the access rules you set in the contract.

Switzerland is in DACH, but it is not in the European Union. A Swiss region, an EU region, or a split in which only certain logs stay in one place, are all engineering options. Which legal regime applies is a question for your counsel, not something I will certify. The same limit applies to GDPR and the EU AI Act: I can document tools, rules, evals and an audit trail, as I do in BleedStop's append-only decision log, but I do not claim compliance. The wider practice is on the Europe page.
